# 배경음악, 결말 소리, 그리고 보이는 설정

2026-09-07 · `develop`

## 셋을 한 번에 하는 이유

따로 온 요구지만 전부 같은 곳에서 만난다. 음악은 볼륨 조절이 필요하고, 볼륨 조절은
설정 패널에 살고, 설정 패널은 지금 잘 안 보인다. 결말 소리는 오디오를 건드리는 김에
같이 고친다.

## 1. 결말이 무음이다

```js
const sleep = () => {
  if (day >= DAYS) {
    setShipped(true);
    return;        // ← sfx.play("click") 앞에서 빠져나간다
  }
  sfx.play("click");
```

12일차 밤에 침대에 누우면 소리 없이 별점 화면으로 넘어간다. 출시 화면 렌더에도
`sfx.play`가 없다. 12일을 굴린 결과가 나오는 순간인데 아무 소리도 안 난다. 매일 밤
잠들 때는 `click`이 울리므로, **마지막 밤만 예외**다.

**고침:** `setShipped(true)` 앞에서 평점에 따라 소리를 낸다. `shipRating`이 0~5를
주므로 **3 이상이면 `success`, 미만이면 `fail`**. 같은 소리를 내면 결과를 말하는 게
아니라 화면 전환음이 된다.

## 2. 배경음악

### 음원

[JRPG Piano](https://opengameart.org/content/jrpg-piano) — 저자 Joth, **CC0**.

파일을 직접 검사한 값: MPEG1 Layer III, 44100 Hz, 160 kbps, joint stereo,
953 프레임, **24.89초**, 501,990 바이트. ID3v2.2 태그 4,086 바이트 포함.

`public/audio/jrpg-piano.mp3`에 넣는다 — 이름의 공백을 없애고, `src/assets/`가 아니라
`public/`인 이유는 번들에 들어가지 않고 필요할 때 받아지게 하기 위해서다.

### MP3를 그냥 반복하면 안 된다

`<audio loop>`로 MP3를 돌리면 루프 지점에 미세한 공백이 생긴다. 인코더가 파일 앞뒤에
패딩을 넣기 때문이고, 이 파일의 문제가 아니라 형식의 문제다. 25초 루프면 그 공백이
25초마다 오고, **작게 깔린 소리일수록 더 티가 난다** — 조용한 바탕에서는 소리가
나는 것보다 끊기는 쪽이 눈에 띈다.

**그래서 WebAudio 버퍼로 돌린다.** 파일을 한 번 받아 `decodeAudioData`로 디코드하고
`AudioBufferSourceNode`에 `loop = true`를 건다. 샘플 단위로 이어지므로 공백이 없다.
25초 스테레오 44.1kHz면 메모리로 약 9MB인데, 한 번 디코드하고 계속 쓴다.

곁가지 이득: 페이드를 게인 노드로 정확히 걸 수 있고, `sfx.ts`가 이미 쓰는 패턴이다.

### 어디서 울리나

`Office.tsx`가 이미 `place`를 알고 있으므로 규칙은 한 곳에 산다.

| 장소 | 음악 |
|---|---|
| `home` (집) | **울린다** |
| `lane` (골목) | **울린다** |
| `street` (큰길) | **울린다** |
| `office` (사무실 층) | 무음 |
| 기기로 여는 빌드 (카드 빌드 포함) | 무음 |
| 출시 화면 | 무음 |
| 개발용 화면 (`?debug` `?lab` `?repro`) | 무음 |

빌드는 `place === "office"` 위에서 열리므로 따로 처리할 게 없다 — 저절로 조용하다.
출시 화면도 세 장소 중 어디도 아니라 저절로 꺼지고, 그래서 결말 소리가 깨끗하게
들린다.

전환은 **600ms 페이드**. 방을 자주 넘나드는 게임이라 딱 끊으면 매번 튄다.

### 소리 크기

들릴듯말듯이 목표다. **음악 슬라이더 기본값 30%.** 효과음은 기본 100%가 맞지만
(눌렀는데 소리가 없으면 고장으로 읽힌다) 음악은 처음부터 낮아야 의도한 소리가 된다.
아무것도 안 만진 사람이 듣는 것이 원하는 그 소리여야 한다.

### 자동재생 차단

음악은 침실에서 시작되는데 그 시점엔 아직 사용자 조작이 없어 브라우저가 막는다.
**재생 실패를 정상 경로로 취급한다** — 막히면 조용히 기다리다가 첫 조작에서 다시
시도한다. 아침 카드의 `닫기`가 사실상 항상 그 첫 조작이라 실제로는 거의 즉시
시작된다.

로딩 화면은 음악을 기다리지 않는다. 지금 `preloadArt`가 아트만 기다리는데 거기에
음원을 얹으면 첫 화면이 그만큼 늦어진다.

### 새 파일 `src/audio/music.ts`

`sfx.ts`와 분리한다. 효과음은 WebAudio 합성이고 음악은 받아온 파일이다 — 수명도
제어도 다르다. 한 파일에 넣으면 둘 다 읽기 어려워진다.

바깥에 내놓는 것:

```
music.wants(on: boolean)   // 이 화면에 음악이 있어야 하나
music.setVolume(0..1) / getVolume()
music.setMuted(bool) / isMuted()
```

게인 노드는 `sfx`의 마스터와 **따로** 둔다. 그래야 슬라이더 둘이 진짜로 독립이다.

음원 경로는 상수 하나로 둔다. 저자가 "요청하면 확장 버전을 만들어준다"고 적어놨으니
나중에 더 긴 파일로 갈아끼울 수 있어야 한다.

## 3. 설정이 잘 안 보인다

기어 버튼은 `opacity: 0.5`에 13px 아이콘이고 왼쪽 아래 구석에 있다. 흐린 것은
의도였지만, 바로 위 주석이 스스로 약점을 적어놨다:

> and it only came back on hover, which on a phone is never.

즉 **폰에서는 13px 반투명 아이콘이 구석에 영원히 앉아 있다.** 게다가 이번에 슬라이더가
하나 늘어 패널이 언어 · 효과음 · 음악 · 상점 · 기록 다섯 구획이 된다.

**고침 둘:**

- **기어 버튼** — 쉬는 상태 불투명도를 0.5에서 0.85로 올리고, 바닥 위에서 읽히도록
  배경 칩을 준다(`.floor-controls button`이 이미 쓰는 것과 같은 방식). 크기는 그대로
  둔다 — 게임 화면과 경쟁하면 안 된다.
- **패널** — 폭 186px에 10px 라벨로 다섯 구획은 좁다. 폭을 210px로, 라벨을 11px로
  올린다.

이건 "설정도 더 잘보이게"를 **진입점과 패널 양쪽**으로 읽은 것이다. 한쪽만 원했다면
말해달라.

## 검증

- `npm run verify`가 5개 언어 키를 강제한다
- 브라우저에서 장소별로 확인: 집·골목·큰길에서 소리가 나고, 사무실·빌드·출시 화면에서
  안 나는 것
- 루프 이음매: 25초를 넘겨 두 바퀴 이상 돌려 공백이 없는지
- 기본 볼륨이 30%로 시작하는지, 슬라이더 둘이 서로 독립인지
- 12일차 결말에서 평점에 따라 다른 소리가 나는지

## 하지 않는 것

- 장소별로 다른 곡 — 음원 하나로 시작한다. 모듈이 경로 상수를 쓰므로 나중에 늘릴 수 있다
- 낮/밤 변주 — 같은 이유
- 효과음과 음악을 한 슬라이더로 묶기 — 음악만 끄고 싶다는 요구가 흔하고, 이 게임은
  효과음이 판정 피드백이라 더 그렇다
